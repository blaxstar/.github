# Contributing to BLAXSTAR

Thank you for taking interest in contributing!

BLAXSTAR projects aim to remain approachable, well structured, and useful. Contributions should improve clarity, reliability, performance, or usability.

Before starting work, consider opening an issue to discuss the change. This helps avoid duplicate work and keeps direction aligned.

## General expectations

Write code that is easy to understand and maintain.

Prefer small focused changes instead of large sweeping rewrites.

Follow the existing structure of the repository when possible.

Include documentation updates when behavior changes.

Test functionality when appropriate.

## Pull requests

Keep pull requests focused on a single improvement.

Describe what changed and why it changed.

Reference related issues when applicable.

Avoid unrelated formatting changes unless the repository specifically requests them.

## Issues

Issues may include bug reports, feature ideas, documentation improvements, or questions.

Clear reproduction steps are always helpful for bug reports!!

## Conduct

Respectful collaboration leads to better results!

Curiosity and thoughtful discussion are encouraged.
