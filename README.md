# BLAXSTAR

BLAXSTAR is a technology studio focused on building reliable software, useful tools, and creative systems that solve real problems. We enjoy working across the full stack, from hardware-aware utilities and infrastructure tooling to modern web applications, automation workflows, and experimental interactive software.

Our projects are guided by a practical mindset. Software should be understandable, maintainable, and performant where it matters. We value thoughtful design, accessibility, and clear architecture, because tools that are easy to reason about are easier to improve over time.

Some of our work focuses on everyday technical needs, including diagnostics software, configuration utilities, automation helpers, and deployment tooling. Other projects explore more creative directions such as simulation software, interactive experiences, and games.

BLAXSTAR is interested in the space where reliability and curiosity overlap. We believe experimentation leads to better tools, and better tools create more room to experiment.

Technologies vary by project, but often include TypeScript, Node.js, Rust, modern web frameworks, and Linux based infrastructure.

If something here is useful to you, or if you would like to collaborate, contributions and discussions are always welcome.
